Integer

noun · Computer science

Definition

A whole number, positive, negative or zero.

Explanation

Integers do not have fractional parts.

Example

7 and minus 3 are integers.

Common confusion

An integer is not the same as a float, which can have decimals.

Related terms

  • Data typeThe kind of value a variable holds, such as integer, string or Boolean.
  • StringA sequence of characters, such as text.
