Argument

noun · English

Definition

A claim supported by reasons and evidence.

Explanation

In academic writing, an argument is not a quarrel; it is a reasoned case for a position.

Example

The policy should change because the evidence shows it is ineffective.

Common confusion

An argument needs reasons. An opinion alone is not an argument.

Related terms

  • EvidenceFacts, data, examples or sources used to support a claim.
  • FallacyAn error in reasoning that weakens an argument.
