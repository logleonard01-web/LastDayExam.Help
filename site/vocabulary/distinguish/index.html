Distinguish

verb · Command words

Definition

Show the difference between two or more things.

Explanation

State what makes each one unique and how it can be told apart.

Example

Distinguish between speed and velocity.

In an exam

Command-word meanings can vary between subjects, exam boards and mark schemes, so check your own board's guidance. See Exam Command Words: What Each Instruction Asks For.

Common confusion

Distinguish focuses on differences that identify each item.

Related terms

  • ContrastFocus on the differences between two or more things.
  • ClassifySort items into groups according to shared features.
