Pseudocode

noun · Computer science

Definition

A structured way to describe an algorithm that looks like code but is not tied to any language.

Explanation

It focuses on logic, not syntax.

Example

IF score >= 70 THEN PRINT Pass.

Common confusion

Pseudocode cannot be run directly.

Related terms

  • AlgorithmA finite, ordered set of clear steps for solving a problem.
  • FlowchartA diagram that shows the steps of a process using shapes and arrows.
