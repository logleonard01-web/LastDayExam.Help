Key vocabulary

  • AlgorithmA finite, ordered set of clear steps for solving a problem.
  • BooleanA data type with two possible values, true or false.
  • Data typeThe kind of value a variable holds, such as integer, string or Boolean.
  • FlowchartA diagram that shows the steps of a process using shapes and arrows.
  • IntegerA whole number, positive, negative or zero.
  • IterationThe repetition of a set of instructions.
  • PseudocodeA structured way to describe an algorithm that looks like code but is not tied to any language.
  • StringA sequence of characters, such as text.
  • Variable (programming)A named location in memory that stores a value which can change.
